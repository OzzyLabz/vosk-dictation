# 🗣 VOSK Dictation

> 🎤 Говоришь голосом — получаешь текст. Офлайн. В активном поле ввода.

VOSK Dictation — программа для голосового ввода на Linux. Она работает в фоне: отдельного главного окна нет, управление доступно через значок в системном трее.

---

## 🚀 Как работает?

1. Удерживай **левый Alt** 1,2 секунды — начнётся запись.
2. Повторно удержи **левый Alt** 1,2 секунды — запись остановится.
3. Программа распознает речь и вставит текст в поле, которое активно **в момент вставки**.

📌 Распознавание выполняется локально с помощью русской модели VOSK. Для диктовки интернет не нужен.  
🟢 Пока значок находится в трее, программа работает в фоне и готова к записи.  
❌ Чтобы закрыть программу, выбери **«Остановить»** в меню значка.

💡 Перед началом записи открой нужное поле ввода. До завершения распознавания оставь его активным.

---

## 🔔 Уведомления и звук

Программа сообщает о запуске, записи, распознавании и результате. Системные уведомления появляются, если в системе доступен `notify-send` и работает служба уведомлений.

Звуковые сигналы воспроизводятся через доступный в системе `pw-play` или `paplay`. Если звуковой проигрыватель или аудиослужба недоступны, диктовка продолжит работать без сигнала.

---

## 🧩 Особенности

- 🧠 Офлайн-распознавание речи с помощью VOSK.
- 🇷🇺 Русская модель `vosk-model-small-ru-0.22`.
- ⌨️ Управление удержанием левого Alt.
- 🧙 Вставка текста в активное поле с помощью `xclip` и `xdotool`.
- 🧪 Значок в системном трее с пунктом **«Остановить»**.
- 🧼 Распространение одним файлом AppImage.

Вставка использует буфер обмена: его прежнее содержимое может быть заменено распознанным текстом. Встроенная расстановка знаков препинания не предусмотрена.

---

## 🖥️ Системные требования

- Linux **x86_64** с графической сессией **X11**.
- Совместимая системная `glibc`.
- Для обычного запуска AppImage — поддержка **FUSE 2**. Если её нет, содержимое AppImage можно извлечь и запустить через `AppRun`.
- Микрофон и доступ к устройству записи звука.
- Системный трей для отображения значка.

Python, русская модель VOSK и основные компоненты диктовки входят в AppImage. Уведомления и звуковые сигналы используют доступные средства системы.

---

## 🧾 Совместимость

Программа предназначена для дистрибутивов Linux **x86_64** с X11 и совместимой `glibc`, включая семейства Ubuntu, Linux Mint, Debian, Kali Linux, Fedora, Arch Linux и openSUSE при выполнении системных требований. Возможность обычного запуска AppImage зависит от поддержки FUSE 2 в конкретной системе.

В сессии **Wayland** управление клавишей и вставка через `xdotool` могут работать иначе или быть недоступны. Для этой версии используй **X11**.

## 📎 Запуск

Скачай файл `VOSK_Dictation-1.2.3-r2-x86_64.AppImage` из [релиза v1.2.3](https://github.com/OzzyLabz/vosk-dictation/releases/tag/v1.2.3), затем в папке с файлом выполни:

```bash
chmod +x VOSK_Dictation-1.2.3-r2-x86_64.AppImage
./VOSK_Dictation-1.2.3-r2-x86_64.AppImage
```

Программа запускается из AppImage; устанавливать Python и модель VOSK отдельно не нужно.

---

## 📌 Если AppImage не запускается

Если системе не хватает FUSE 2, извлеки содержимое AppImage и запусти приложение из полученной папки:

```bash
./VOSK_Dictation-1.2.3-r2-x86_64.AppImage --appimage-extract
./squashfs-root/AppRun
```

Первая команда создаёт папку `squashfs-root`, вторая запускает программу из неё. Для извлечения также нужен исполняемый AppImage — при необходимости сначала выполни команду `chmod +x` из раздела выше.

Если программа запущена, но окна не видно, проверь значок в системном трее: отдельного главного окна у VOSK Dictation нет.
